# Инструкция по настройке проекта

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта (или скопируйте `.env.example`):

```bash
cp .env.example .env
```

Отредактируйте файл `.env`:

```env
# Пароль для входа в приложение
VITE_APP_PASSWORD=your_secure_password

# URL вашего сервера PocketBase
VITE_POCKETBASE_URL=http://127.0.0.1:8090
```

**Важно:** 
- Никогда не коммитьте файл `.env` в репозиторий!
- Для продакшена используйте надёжный пароль
- Укажите правильный URL вашего сервера PocketBase

### 3. Запуск приложения

```bash
# Режим разработки
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 📦 Настройка PocketBase

### Коллекции в базе данных

Создайте следующие коллекции в вашем PocketBase:

#### 1. `seasons` (Сезоны)
- `title` (text) - Название сезона (например, "Сезон 2024/25")
- `is_active` (bool) - Активен ли сезон

#### 2. `teams` (Команды)
- `name` (text) - Название команды
- `group` (text) - Группа (A или B)
- `base_u` (number) - Базовое количество сезонов
- `base_i` (number) - Базовое количество игр
- `base_v` (number) - Базовые победы
- `base_n` (number) - Базовые ничьи
- `base_p` (number) - Базовые поражения
- `base_goals_scored` (number) - Базовые забитые голы
- `base_goals_conceded` (number) - Базовые пропущенные голы
- `base_points` (number) - Базовые очки

#### 3. `scorers` (Бомбардиры)
- `name` (text) - Имя игрока
- `team_id` (relation) - Ссылка на команду
- `base_goals` (number) - Базовое количество голов

#### 4. `matches` (Матчи)
- `season_id` (relation) - Ссылка на сезон
- `team_id` (relation) - Ссылка на команду
- `opponent` (text) - Команда соперника
- `team_score` (number) - Голы нашей команды
- `opponent_score` (number) - Голы соперника
- `scorers_list` (json) - Список бомбардиров в матче

#### 5. `euro_teams` (Еврокубки - команды)
- Аналогично `teams`

#### 6. `krasnodar_players` (Краснодар - игроки)
- Аналогично `scorers`

#### 7. `krasnodar_matches` (Краснодар - матчи)
- Аналогично `matches`

### Настройка прав доступа

Для каждой коллекции настройте правила доступа:

- **Create**: authenticated users only
- **Read**: public (или authenticated, если нужна авторизация)
- **Update**: authenticated users only
- **Delete**: authenticated users only

## 🔒 Безопасность

### Рекомендации по безопасности

1. **Пароль приложения**
   - Используйте сложный пароль (минимум 12 символов)
   - Регулярно меняйте пароль
   - Никогда не храните пароль в коде

2. **PocketBase**
   - Включите HTTPS для продакшена
   - Настройте брандмауэр
   - Регулярно делайте бэкапы базы данных
   - Используйте аутентификацию через API вместо пароля в коде (рекомендуется для продакшена)

3. **Переменные окружения**
   - Файл `.env` добавлен в `.gitignore`
   - Используйте `.env.example` как шаблон
   - Для разных сред (dev, prod) используйте разные файлы

## 🛠 Решение проблем

### Ошибка подключения к PocketBase
- Проверьте, запущен ли сервер PocketBase
- Убедитесь, что URL в `.env` правильный
- Проверьте сетевые настройки и брандмауэр

### Ошибка "Неверный пароль"
- Проверьте значение `VITE_APP_PASSWORD` в `.env`
- Перезапустите dev-сервер после изменения `.env`

### Данные не загружаются
- Проверьте наличие коллекций в PocketBase
- Убедитесь, что коллекции имеют правильную структуру
- Проверьте консоль браузера на ошибки
